# LLM prompts used during development

The assignment requires this file to contain the prompts used while building the application. Replace or extend the entries below with the exact prompts used during your own build session before submitting the repository.

## Prompt 1

Read the uploaded OTP Based User Login assignment line by line. Identify every functional requirement, artifact, layer, and deployment requirement. Design a small implementation that follows the document exactly without adding unrelated features.

## Prompt 2

Develop the registration, email recognition, OTP login, skip-login, session, and checkout persistence flow with distinct frontend, API, and PostgreSQL layers. Keep the code readable and realistic for a two-day take-home assignment.

## Prompt 3

Review the implementation against the assignment document and check that every required flow works, including background email recognition, OTP mismatch handling, skip login, logged-in user name, database persistence, SQL schema, and deployment readiness.

## Prompt 4

Make the UI and code straightforward and human-maintained: clear variable names, small components/functions, limited comments, no unnecessary abstractions, and no unrelated features.
